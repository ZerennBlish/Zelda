# Investigation Records

Use this folder for a bounded investigation that needs a durable evidence trail. Name each record by session, item, and topic, such as `S05-Z004-Pipeline-Write-Route.md`. Create a record when the investigation runs; do not create fictional completed recon.

Each record should include:

- The question and exact scope.
- Branch, revision, and relevant dirty files at inspection time.
- Source anchors and any observed Unity project/scene state.
- Evidence, commands used, and their results.
- Confirmed conclusions, unresolved hypotheses, and the next bounded check.

Link open work to [Tracked-Items.md](../Tracked-Items.md). Put durable decisions in [Zerenn-Decisions.md](../Zerenn-Decisions.md), not only in an investigation record.
